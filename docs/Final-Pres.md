# ASE-Capstone PPP

## Problem Domain

- Many people aren't familiar with terminals
  - difficult to jump in
- A game can teach basic concepts
  - give instant feedback

---

## Solution

- Terminal-based character controller
- Commands that are similar to/the same as real world command lines
- Combat encounters to test knowledge

---

## LoC and Burndown Rate

LoC: 1,568
Requirements: 7 / 7 (100%)

## Sprint 2 Features and Requirements

1. A terminal that acts as a controller
   1. user can create scripts that can allow them to automate/optimize actions
2. Enemies
   1. AI determined by scripts similar to what the player may create for themself
   2. varying levels of difficulty/complexity of enemies
3. Combat system    
   1. User can test knowledge of commands or efficiency of scripts against enemies
4. Main level
   1. combat encounters
   2. environmental hazards
   3. win state
